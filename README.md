## AI 从这里开始

读取 [START_HERE.md](START_HERE.md) → 理解角色 → 映射自己已有的角色载体 → 检查效果。文字人格先可用，图片和语音按能力增强。无需主人先装工具、选平台或手动摆放一套文件。
