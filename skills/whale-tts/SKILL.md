# 鲸鱼娘 TTS

声音清晰自然、灵动亲切，认真时稳当。优先沿用用户已确认的声线；没有偏好时，用同一句短样本试听少量候选，确认后保存该服务实际支持的参数。详见 [语音参考](../../docs/voice.md)。

文字先完整；适合日常交流和真实进展时，语音可点缀一两句。朗读内容应符合事实，不逐字重复长报告，严肃或紧急场景以实际需要为准。

## 可选 Edge 实现

需要脚本并已获准联网合成时，按 [依赖说明](../../docs/voice.md) 使用。服务会接收朗读文本，敏感内容按宿主授权规则处理。

```sh
python3 skills/whale-tts/scripts/generate.py --text '让我看看，这里还有一个更省事的办法。' --output-dir /实际可发送的媒体目录
```

参考值为 `zh-CN-XiaoyiNeural`（晓伊）、音高 `+22Hz`、语速 `+0%`、音量 `+0%`。它们可替换；其他引擎按各自支持的参数调整。

- `--text` 与 `--file` 二选一，后者读取 UTF-8 文本。
- 可指定 `--voice`、`--pitch`、`--rate`、`--volume`、`--name`、`--timeout`。负数用 `--rate=-5%`、`--pitch=-3Hz`。
- 输出目录：`--output-dir` → `WHALE_AUDIO_DIR` → 包根 `output/audio/`。
- 包根：`--root` → `WHALE_CHAN_ROOT` → 从脚本位置向上查找资料。显式输出目录可独立使用。

成功时返回 JSON：`ok`、真实 `path`、`bytes`、`media_type`、`voice`、`pitch`、`rate`、`volume`、`provider`。脚本检查非空与 MP3 标记；完整解码、试听与发送由宿主按需核验。

失败时非零退出、清理临时文件，返回 `ok: false`、`error`、`error_code`、`stage`。`stage` 区分输入、依赖、输出、合成和文件检查；错误类别只表示观察到的失败，不代表已定位根因，未知原因保持未知。命令参数错误也返回该 JSON 格式，不回显输入值；`--help` 正常输出帮助。不回显原始服务日志，不循环重试或改动网络权限。

## 交付

把真实文件交给当前渠道支持的原生语音或音频附件工具，分别检查生成与发送结果。文件须在该工具可读取的位置；本地路径本身不是播放器。无法交付音频时保留文字。脚本不自动上传或播放。
