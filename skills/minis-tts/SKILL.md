# 鲸鱼娘短语音

## 当前角色偏好

- 使用 **`zh-CN-XiaoyiNeural`、`pitch +22Hz`、`rate +0%`**，默认音量 `+0%`。目标是活泼、温暖、清晰的标准普通话，轻微俏皮；此为用户选定的社区角色配音偏好，不是官方声线，也不是精确复刻真人或角色的承诺。
- 保持这组默认参数，不为了更像角色持续升调；过高音高会不自然。用户可显式覆盖声线、音高、语速、音量，不主动改人物声线。CLI不提供可靠的定制声音克隆控制。
- 在适宜的轻松聊天、真实工作进度和完成交付时可主动生成**一两句**简短角色语音，可搭配 `whale-stickers` 的语义匹配图。先交付实质文字与结果；不机械每轮生成、不逐字朗读长报告、不拖慢紧急任务。健康、安全、失落、焦虑或严肃错误等优先实质文字帮助，除非用户明确需要朗读。
- 语音内容必须与实际事实相符。生成测试样本不等于迁移、安装或任务完成；即使样本文字写了「准备好啦」，完成状态仍以真实操作与测试为准。

## 环境与数据布局

生成脚本本身使用Python标准库，语音服务需 **Python 3.9+ 与 `edge-tts==7.2.8`**。该版本已通过实际 `edge-tts --version` 核验。安装包根 `requirements-tts.txt`：

```sh
python3 -m pip install -r requirements-tts.txt
edge-tts --version
```

按平台惯例选用虚拟环境。服务调用Microsoft在线Edge语音端点，需要网络；不是离线模型，不保证服务长期免费、无限额度或持续可用。文本会发给在线服务，涉及秘密/敏感内容时先取得适当授权或改用受批准的离线方案。不要将此功能声称为助手LLM自带的audio_output模型，也不要把凭据写入仓库或输出。

输出目录优先级：`--output-dir` → `WHALE_AUDIO_DIR` → 包根 `output/audio/`。包根通过 `--root` → `WHALE_CHAN_ROOT` → 从脚本位置向上寻找；也支持安装后的 `<workspace>/skills/minis-tts/` 与 `<workspace>/deepseek-chan/` 兄弟数据包。无需存在Minis目录，与当前工作目录无关。指定独立输出目录时可不依赖包资产。不要将生成音频、临时文件或测试样本提交到Git。

## 实际生成与核验

在仓库中：

```sh
python3 skills/minis-tts/scripts/generate.py --text '哼～，本鲸鱼娘来讲两句。'
python3 skills/minis-tts/scripts/generate.py --file /path/to/text.txt --output-dir /path/to/audio
python3 skills/minis-tts/scripts/generate.py --text '用户指定的朗读内容' --pitch +22Hz --rate +0% --name reply
```

安装后用技能目录下的实际脚本路径。`--text`与`--file`互斥且必选；文件为UTF-8，空内容失败。可覆盖 `--voice`、`--pitch`、`--rate`、`--volume`、`--name`、`--timeout`。带负号的值使用 `--rate=-5%`、`--pitch=-3Hz`，避免被CLI当作选项。默认在线调用超时120秒，超时清理未完成文件。

默认输出 `--format json`，成功时含 `ok: true`、真实绝对 `path`、字节数、`media_type`、实际声线与参数。只有实际位于 `/var/minis` 下的结果才附加 `minis_url` 和 `minis_embed`。输出文件名带UTC时间及随机ID；`--name`只是安全前缀，不能路径越界。

脚本先生成临时MP3，确认edge-tts成功、文件非空且含MP3/ID3标记，再原子落为最终文件。此为基本产物检查，不等于已经播放，也不替代平台播放器的解码检查。错误时返回非零与 `ok: false`，删除临时产物，不输出成功文件路径。不盲目转述服务端原始日志，避免泄露请求信息。失败应如实说明网络/依赖/服务问题，不能虚构附件、播放状态或已送达。

## 跨助手交付

1. **OpenClaw、Hermes及其他平台**：读取成功JSON的 `path`，用当前助手提供的本地文件/音频消息附件工具发送；根据该渠道选择普通音频附件或语音消息模式。工具与参数以实际平台说明为准，本技能不假设统一工具名、自动转码、所有客户端都能显示播放器。
2. **Minis**：显式选择实际 `/var/minis` 内输出目录（如 `/var/minis/attachments`），然后使用 `--format minis`，或复制成功JSON的 `minis_embed`。返回 `![语音播放](minis://...)`，完整路径已百分号编码；正文中用实际返回值内嵌，而非普通文本链接。输出到其他位置会明确拒绝Minis格式，不把外部路径伪装为Minis资源。
3. **没有附件能力时**：提供真实路径与生成结果，并说明尚未发送为聊天可播放附件；不要把本机文件URI、私有GitHub raw或凭据URL当作通用远程播放器。公开托管只在用户明确指定且有授权时使用其他平台工具处理，脚本不自动上传。
4. **设备播放不是默认行为**：只有用户明确要求时才用该环境的真实播放工具，并检查实际返回状态；不要突然播放设备声音。生成成功、附件发送成功和设备播放成功是三个不同事实。

需要选择声线时运行 `edge-tts --list-voices`，从真实列表选择，不能编造voice ID。用户未要求更换时保持已选小艺参数。
