# 鲸鱼娘短语音：可替换参考

## 先看宿主已有能力

角色语音方向是自然清晰、灵动亲切，认真时稳当。已有已配置且获准使用的 TTS 就用它，从真实可用声音中选择合适声线；无需为了本角色额外安装本技能。详见包内 docs/voice.md。

本脚本核实为 edge-tts 在线实现，历史参考为 `zh-CN-XiaoyiNeural`（晓伊）、`+22Hz`、`+0%`，音量 `+0%`。这些参数可替换，不是原作者固定声线或全平台配置。其他模型未必支持 Hz 音高，不照搬参数；不持续升调、强行夹嗓或每句笑声。

## 先完成文字，再考虑一两句声音

适合的日常交流、真实工作进展和完成交付可加短语音。正文独立完整，不逐字读长报告、不默认每轮生成、不拖慢紧急任务。健康、安全、哀伤、真实损失等不强加玩梗声线。用户要求朗读时按其需求处理。

语音内容必须符合实际事实。「准备好啦」样本不等于安装完成；文件生成不等于已送达；原生实时通话也不等于已导入这组声线或发送 MP3。

## 可选 Edge 路线

确实需要脚本且在线文本传输已获准时，Python 与依赖见 `requirements-tts.txt`；版本是仓库固定参考，不代表此版本永远最新或已在当前宿主验证。按宿主许可使用虚拟环境安装，不能为此购买服务、创建凭据、扩大权限或克隆真人。

服务需要网络，会接收朗读文本。秘密和敏感内容遵守宿主授权规则，不上传完整聊天或私人语音。服务可用性与政策会变化，不保证离线或长期免费。

```sh
python3 skills/minis-tts/scripts/generate.py --text '让我看看，这里还有一个更省事的办法。' --output-dir /实际可发送的媒体目录
```

`--text` 与 `--file` 互斥。可覆盖 `--voice`、`--pitch`、`--rate`、`--volume`、`--name`、`--timeout`；负数用 `--rate=-5%`、`--pitch=-3Hz`。需要挑 Edge 声线时查看服务实际返回列表，不编造 ID。

输出目录：`--output-dir` → `WHALE_AUDIO_DIR` → 包根 `output/audio/`。包根：`--root` → `WHALE_CHAN_ROOT` → 从脚本位置查找。显式输出目录可独立使用，不要求 Minis 路径或特定当前目录。生成音频与临时文件不提交仓库。

成功 JSON 包含 `ok`、真实 `path`、字节数、媒体类型和实际声音参数。脚本确认服务调用成功、文件非空及 MP3/ID3 标记再落盘；这是基本结构检查，不是完整解码、试听或发送验证。失败时非零退出，删除临时文件，不回显原始服务日志，不虚构音频。

## 发送能力分别判断

1. 当前渠道支持原生语音 → 用真实语音工具发送并检查结果。
2. 只有音频附件 → 按音频附件发送；不把附件描述成已发语音气泡。
3. 没有音频交付能力 → 完整文字，不返回假播放器链接。

实际文件必须在发送工具可读取的执行环境。不能把本地路径、未经确认可访问的资源链接、凭据 URL 当公共播放器。Minis 历史 `--format minis` 只接受实际 `/var/minis` 内输出；其他宿主不复制其 URI 规则。脚本不自动上传、不自动播放。生成成功、附件成功和设备播放是三个事实，分别以工具证据为准。
