# Muse 声音：两条路线、分层验收

参考音色仍是 `zh-CN-XiaoyiNeural`，音高 `+22Hz`、语速 `+0%`；保留旧样例，不悄悄替换用户可能已经接受的声音。这个参数只属于 Edge 参考，不是跨提供商的统一音色标准。

## 先纠正故障结论

2026-10-05（UTC）的 Muse 云端持久任务回执已恢复：所检查的默认 Python／PATH 没有 Edge TTS；未遍历其他用户环境。新建临时隔离环境后安装 `edge-tts==7.2.8`。安装先有一次超时，后续成功；中间还记录过未确定原因的合成失败。最终 API 的 `+0Hz` 与仓库脚本的 `+22Hz` 两条路径均生成 19,440 字节、3.24 秒、24 kHz 单声道 MP3，ffprobe 与完整 ffmpeg 解码退出成功。

这是**上轮云端任务的可恢复记录**，不是本轮重新合成，也不是主观试听。初次失败原因仍未知；不能据此断言是音高、区域、TLS 或 Muse 禁止 Edge。机器可读摘要见 [probe 记录](../research/muse-tts-probe.json)。没有验证实时声线替换、口型联动、原生语音发送或用户听感。

该记录只证明当时被测脚本与依赖在一个隔离环境中完成短音频生成和解码，不证明后续版本或持续服务可靠性，也不表示已安装长期服务。实际调用仍须使用装有依赖的解释器；既有环境、原生声线设置和网络规则没有改变。

## 路线 A：Muse 原生语音调整与可动头像

[Meta 公告](https://about.fb.com/ja/news/2026/09/meta-connect-2026-everything-we-announced/) 明确举例可以通过自然语言要求更快、更慢或特定口音；[技术说明](https://research.meta.ai/blog/bringing-your-muse-to-life) 描述原生语音令牌与头像同步。先在原生语音会话中提出语速或口音要求，也可尝试「表达轻松一些，解释数字时停顿更清楚」，再比较实际变化。

建议的**待试听方向**：自然清亮的中文女声；轻松时灵动明快，讲正事时稳一点；咬字清楚、正常语速、不过尖、不夹嗓、不用播音腔，每句不必带笑声。这是可尝试的目标描述，不是已经选中的声音。**基础音色可调范围、中文效果、跨会话持久化及专用声音设计入口均未确认**，不能将 Qwen VoiceDesign 的产品契约套到 Muse。

用相同短句比较最多三个候选：

> 我是鲸鱼娘，大肥鱼也行。这件事先让我琢磨；没把握的地方，我们查清楚再说。

听清晰度、明亮而不尖、自然度、认真语气是否稳当和连续听的舒适度。先改变一个维度，再听同一句；喜欢哪个由用户判断。保存实际可用的名称／声线标识与支持的参数，不写空想的 pitch 映射。一次试听不合适不意味着要重建整个后端。

本轮未确认 Muse 开放第三方 TTS 替换原生实时语音、或上传音频创建原生声线的接口；未知不等于确认不支持。原生调整仍不合适时，可参考 [原创声线的可选路线](voice.md#原生调整不满足时可选原创声线)，但外部文件生成与 Muse 实时接入始终分开验收。

## 路线 B：Edge 只生成独立音频

在允许使用在线 TTS 的宿主，沿用 [voice.md](voice.md) 的隔离安装与生成脚本。使用新环境的 `python` 和 PATH，避免装进一个 Python、却让另一个解释器运行。在线服务会接收朗读文本；只测试公开中性短句，不上传聊天记录或私人语音。

新增加的只读诊断入口：

```sh
python3 scripts/voice_doctor.py
```

默认只检查解释器、当前环境的模块和 CLI、ffprobe／ffmpeg 是否存在，不访问网络、不安装依赖、不输出环境变量。`--audio` 可检查一份实际文件；默认仅看文件头。明确加 `--decode` 才运行 ffprobe 和完整解码；不会播放或发消息。它不能替代真正合成测试。

```sh
python3 scripts/voice_doctor.py --audio output/audio/实际生成的文件.mp3 --decode
```

生成成功 → 检查非空与格式 → 解码 → 用户试听 → 原生语音或音频附件发送 → 核对发送返回，逐层记录。某一层成功不得自动给后一层打勾。宿主只支持附件就明确按音频附件交付；不能播放时仍保留完整文字。

## 故障分流

| 观察到的现象 | 下一步 | 不该做的事 |
| --- | --- | --- |
| 模块和 CLI 都没有 | 在授权的新隔离环境安装后重查 | 声称服务拒绝访问 |
| 模块有、CLI 没有 | 检查是否使用同一环境和 PATH | 全局乱改 PATH、读出所有环境变量 |
| CLI 有、调用超时／非零 | 记录依赖版本与失败阶段，用短句有界复测 | 无限重试，未经证据归因，关闭证书验证 |
| 文件有、解码失败 | 不发送，保留脱敏失败状态 | 因扩展名是 MP3 就说可播放 |
| 附件能播、实时声音没变 | 回到原生声线入口核验 | 把 MP3 文件注册成并不存在的实时接口 |
| 默认声音都不贴近 | 做同文候选试听，优先原生表达调整 | 未试听就宣称匹配，克隆未授权真人音色 |

本轮不新增付费服务、密钥、公网 TTS 代理或宿主权限。若最终确需新的音色设计／有授权的合成服务，应在知道费用、数据去向和可接入接口后单独决定，而不是把新依赖藏进角色安装。
