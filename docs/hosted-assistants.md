# Muse、dot、Hermes 等应用中的使用

主要目标是让宿主能自行理解角色，而非为每个平台交付一套强绑定配置。当前版本没有在用户的 Muse、dot 或 Hermes 实例中安装、改名或端到端试发媒体。

把 [自适配任务模板](../BOOTSTRAP_MESSAGE.md) 交给目标助手即可开始能力检查。模板要求它读 [通用契约](platforms.md)，查清自己真正可编辑的载体与媒体工具，然后在主人授权范围内映射内容。

## 不必相同的部分

- 有的应用是角色字段，有的是提示词、规则、技能或文件。SOUL、Identity、Agent 等称呼只是可能的载体。
- 同一产品不同渠道也可能分别支持图片、语音、音频附件；不能拿一个渠道的测试替所有渠道担保。
- 能生成图片不等于能发送图片；能执行 Python 不等于已安装 Edge TTS；能产生 MP3 不等于已发成语音消息。
- 本地文件在一个执行环境存在，不证明另一个执行环境或消息工具能读取。

## 保留的旧入口

仓库仍有 generic、Hermes、Cursor、OpenClaw 的历史文件布局安装器与 Minis 原始备份，它们供明确需要旧结构的人使用，不是产品接口发现器。若宿主接口已变，应由宿主根据自己的当前文档和工具选择载体，而不是为了兼容本包强行重建旧目录。

旧说明中的第三方产品界面和路径不作为本版兼容性承诺。无需安装器的角色字段导入、原生媒体工具路线都是完整支持的适配方式；缺少媒体能力时完整文字是正常降级。
