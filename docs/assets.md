# 三层图片体系与透明标准

## 1. 形象基准（最高优先级）

`assets/reference/character-fullbody.webp` 保留用户提供的全身三视图原文件，含正面、侧面、背面和鲸尾连接细节。扩充Q版表情时，图像模型应**直接收到三视图 + 已确认的常用Q版原图**，不是只收到文字描述或文件名。三视图负责角色辨识，常用Q版负责脸型、比例和画风。

这套素材是社区二创，不宣称来自 DeepSeek 官方，也不强制使用某个模型提供商。仓库不携带生图API key；使用何种合法可用的图像服务由宿主配置。

## 2. 常用表情（默认发送层）

- `assets/stickers/common/index.json`：33张已校准的**语义真源**，含meaning、usage、SHA256；文件名是历史标签，不替代语义。
- `variants.json`：逐张实际alpha统计与透明状态。21张含真实透明像素，12张是不透明原图。透明不是根据扩展名猜的。
- `usage.md`：分场景说明；`preview.html`：离线预览。
- 所有现有原件逐字节保留。当前没有把不透明图强行抠成残缺图片，也没有把白底/棋盘格图案当透明。

**优先级：语义与适用场景 → 确认的形象 → 真正透明背景 → 格式偏好。** 不为透明而误发表情。21张透明原件供默认优先选用；12张不透明原件仍可在明确合适场景使用。优先透明不意味着每个既有语义已有透明替代版。

### 新图/透明替代版的统一标准

1. 单张、单角色、单动作，主体、手和鲸尾不被裁断；推荐RGBA PNG。
2. 背景alpha真实为0，边缘合理抗锯齿，无白底残留、棋盘格实绘、明显色边；白围裙、头饰、眼白不能被误删除。
3. 以三视图和确认Q版强参考生成，不能凭归档杂图改写角色基准。
4. 保存原图；替代版本单独命名，在元数据记录 `variant_of`、方法、来源、SHA256、审核状态。不能覆写当前原图或静默改语义。
5. 在白、黑、蓝背景上检查轮廓/白色服饰/毛发/鲸尾；核对手、资料和道具接触关系；含文字时逐字检查。
6. **人工确认后**加入常用索引；新候选与归档都不自动晋升。不要为了凑全透明数量把未经确认的图当正式图。

## 3. 参考杂物间（可选归档）

`archive/reference-library/` 对应518张历史图片，可能混有杂图、文字梗、多格图和画风差异。它们只供后来者挑选、研究或作为再生图辅助参考，不进入日常选图范围，也不保证都是合格表情。

为避免每次克隆携带约256MiB杂物间，Git中只放这一层的清单和说明，**所有518张原图片打包在同一私仓 Releases 的 `deepseek-chan-reference-attic-v1.0.0.zip`**。克隆核心仓库即可配置角色；需要归档时用授权的GitHub CLI下载并解压到仓库根目录：

```sh
gh release download v1.0.0 --repo xxnb0/deepseek-chan --pattern 'deepseek-chan-reference-attic-v1.0.0.zip' --dir /tmp/deepseek-chan-download
python3 -m zipfile -e /tmp/deepseek-chan-download/deepseek-chan-reference-attic-v1.0.0.zip .
python3 scripts/verify.py --archive
```

解压前确认当前目录是仓库根目录。原来已排除/待人工审核的候选、历史错误候选和重复ZIP不在本发布中。
