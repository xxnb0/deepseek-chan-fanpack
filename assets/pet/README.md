# 宠物资源入口

本目录保留 [九行网格协议](atlas-profile.json) 与 [逐状态制作简报](generation-brief.md)，供制作、校验新候选时使用。

已恢复并验收的鲸鱼娘动作图、对应元数据、GIF预览与质量回执位于 [成品动作包](../pets/chatgpt/README.md)。提供九行 v1 和带16个额外朝向的十一行 v2；按目标宿主明确支持的格式选择。二者已通过结构预检和视觉复核，保留中间朝向警告，GUI导入／Dot绑定未实测。

完整使用方式与跨平台边界见 [宠物适配](../../docs/pets.md)。本目录的 `pet_asset.py` 配套协议仅用于九行校验；不要拿它直接校验十一行图。原有三视图与33张表情均保留。
