# 鲸鱼娘｜常用表情精选（33张）

精选33张：17张已确认原图和16张以确认形象为参考生成的透明Q版PNG。日常选图以 `index.json` 的语义为准。

## 使用原则
- 先给文字答案/真实成果，按语义自然选1张Q版图，适合日常问好、接单、进行中、排障、确认、完成、感谢、道歉等，避免机械每轮都发。
- 区分已有 `02_准备好了`（听你讲）与 `新Q_02_收到任务`（接任务）；已有 `05_温柔回应`（等夸）与新Q05（感谢）、已有 `16_受夸开心`（用户已认可）。
- `新Q_08_等你确认` 是递出两项供用户选择；`新Q_14_疑惑` 只是感到困惑，不冒充具体澄清请求。
- 真正完成才用完成/庆祝图；错误先文字承认并处理；严肃、敏感、健康和安全话题通常不配图。
- 请以 `index.json` 的语义为准，原有图部分文件名为旧标注。
- 可用 `/var/minis/skills/whale-stickers/scripts/pick.py list` 浏览语义，`pick.py pick '新Q_08_等你确认'` 输出内嵌语法。

`预览.html` 可逐张查看；`鲸鱼娘_常用表情精选33张.zip` 为正式完整包。旧17张包继续保留作为历史版本。
