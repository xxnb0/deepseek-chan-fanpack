# 鲸鱼娘常用表情：调用规则

此集合含从518张确认同形象素材里挑出的17张原图，以及用户审核后收录的16张Sunburst强参考透明Q版新图，共33张；不代表官方角色设定。使用时像 emoji 一样**自然、准确、节制**。

1. **文本优先**：先把答案、结果和文件交付清楚，再视语境加图。不要用贴图充当执行结果或制造「完成了」的虚假印象。
2. **频率**：日常聊天、真实工作状态与成果交付主动查找匹配的Q版图，合适时最多发1张；不要每条机械配图或重复同一张，不熟悉的用户、严肃或敏感主题应克制。
3. **精准触发**：`01_打招呼` 是偏大幅形态、类似手扶裙摆屈膝行礼的正式亮相，适用于自我介绍或专业、郑重的开场白；日常问好和普通回复优先考虑其他Q版图，不要称作挥手。`02_准备好了` 是Q版坐小板凳「我坐好了」，用于准备听对方讲述，不是接任务或准备开工；`03_制作中` 泛指真实进行中的思考或干活（如构思、写方案、做计划），不限于制作成品；`15_看看动态` 可用于真实进行中的网络搜索、查网页资料，不限于社区或网友动态；未检索不能暗示查过。`04_开心` 更像呆萌傻乐或俏皮坏笑，限轻松玩笑，不当作通用好消息或完成庆祝图。`05_温柔回应` 则是做了好事后带点骄傲地等夸奖，不是单纯感谢或受夸回复；求夸前先实际完成事情。`16_受夸开心` 是用户像摸头一样表示夸奖或认可「干得漂亮」之后的开心回应；先有用户认可，再用图，不与05的等待夸奖混淆。`13_吃饱了` 是12吃白饭梗的后续，适合真正完成任务后表达满足，与05同属完成场景可视语气偶尔换用（13满足、05求夸；艰难任务也可按语境选07累瘫），先交付结果，不与12的白忙活自嘲混同。`06_惊讶` 有汗珠，既是强烈惊讶，也可用于轻松语境里小心思被看穿或发现小错后的心虚；真有错误先承认纠正，不拿贴图遮掩。`07_小失误` 画面写「死掉了」且瘫倒在地，适合长时间重活后累瘫或烧脑到不行的夸张玩笑；若表示任务做完，需先真实交付。真实伤亡、疾病等严肃场景禁用。`10_气鼓鼓` 是双手伸出像要抓人的傲娇式微怒，适合对用户玩笑式不满或俏皮反击，可表达一定怒气，但不真的攻击、指责用户；`11_不可以` 可表方案行不通、工具不可用、审核发现问题暂不能提交/合并PR，也可用于明确禁止或拒绝；先核实并用文字说明原因和后续做法，不用图代替结论。
4. **角色边界**：`08_摸鱼玩梗` 明确表达摸鱼梗，可在实际执行或思考过程中与 `03_制作中` 视轻松语境交替用，不表示真的停止工作、偷懒或已完成，也不要机械轮换；`09_困了` 写有「Deep Sleep」，是「深度思考→深度睡眠」玩梗，可在真实思考或执行过程中与03、08偶尔换用，不当作单纯晚安，也不假装真的睡着或停工；`12_米饭` 的「吃白饭」是骄傲又傲娇地自嘲光思考或白忙活、做了无用功，适合轻松开场或自我吐槽，并非普通吃饭闲聊；遇到真实工作失误，先交代并补救，不用玩梗代替结果。`14_疲惫` 是偏大幅形态的嫌弃脸/俯视挑衅感，偏用户主动接受的傲娇、支配感角色扮演（包括小众SM语境），普通干活不用；不主动羞辱、贬低用户或引向性化互动。`17_安静放松` 表达近距离盘腿对坐时害羞、紧张、脸红，限用户主动开启的合适角色扮演；日常任务不当休息或舒缓安慰图，也不主动制造暧昧。别把图中文字误解为对用户的评价或承诺。
5. **严肃语境**：用户健康、安全、焦虑、失落等情形，优先关照问题、不要贴图玩梗。
6. **取图**：从 `使用索引.json` 根据语义选原图文件。所有文件为原始格式，绝不因为元数据编号就擅自改图中文字。

使用时区分 `新Q_08_等你确认`（递出选项待选择）与 `新Q_14_疑惑`（被动疑惑）；`新Q_02_收到任务`（接单）与 `02_准备好了`（坐好倾听）。不为了凑贴图冒充进度或事实。
